MD 排版助手

Markdown 多平台排版浏览器插件（Manifest V3，支持 Edge / Chrome）。
写一次 Markdown，分别排成微信公众号、知乎、掘金可直接发布的格式。

在 Edge 商店安装 下载离线安装包 先试用网页版

已在 Microsoft Edge Add-ons 上架，在商店页点击「获取」即可安装；离线包解压后也可在 edge://extensions/ 开启开发者模式加载。

免费版功能

  • 微信 Tab：Markdown 渲染为微信公众号图文样式，复制后粘贴到公众号后台即可发布；支持多套主题与自定义 CSS。
  • 知乎 Tab：输出干净 Markdown（图片已转为图床链接），一键复制，直接粘贴到知乎编辑器。
  • 掘金 Tab：输出干净 Markdown（代码块语言标注已规范化），一键复制，直接粘贴到掘金编辑器。

免费版功能完整，不阉割、不加水印。文章内容保存在浏览器本地，不上传。

隐私

本插件不收集、不上传任何个人数据。详见隐私政策。
