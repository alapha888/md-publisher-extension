## 名称

MD 排版助手

## 简介（manifest description，≤132 字符）

Markdown 多平台排版助手：微信公众号样式渲染，知乎、掘金干净 Markdown 一键复制。

## 详细说明

MD 排版助手是一个 Markdown 多平台排版工具：

- 微信 Tab：将 Markdown 渲染为微信公众号图文样式，复制后粘贴到公众号后台即可发布；支持多种主题与自定义 CSS。
- 知乎 Tab：输出干净 Markdown（图片已转为图床链接），直接粘贴到知乎编辑器。
- 掘金 Tab：输出干净 Markdown（代码块语言标注已规范化），直接粘贴到掘金编辑器。
- Pro（单独购买）：三平台一键打包导出。

本地运行，文章内容保存在浏览器本地。基于开源项目 doocs/md（WTFPL）构建。
