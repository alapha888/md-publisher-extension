## License 方案（v1：离线校验）

- 激活码格式：`MDPE-XXXXXX-XXXXXX-CCCCCC`
  - 字符集：`ABCDEFGHJKMNPQRSTUVWXYZ23456789`（剔除易混淆的 0/O/1/I/L）
  - 校验：FNV-1a(SECRET + 12 位载荷）→ base32 编码 6 位校验位
- 校验位置：插件内离线校验（`apps/web/src/lib/license.ts`），激活码存于
  `chrome.storage.local`（网页版 fallback 到 `localStorage`）。
- 发放流程（v1 手工）：爱发电收到订单 → 本地运行 `scripts/gen-license-key.mjs`
  生成激活码 → 邮件发给买家 → 买家在插件「帮助 → Pro 激活」中输入。
- 诚实说明：离线校验是防君子不防小人（读代码可伪造）。v2（有收入后）再做
  服务端校验/吊销。`gen-license-key.mjs` 不进公开仓库。

## 发放操作（给运营者）

1. 爱发电商品设为「隐藏待上架」→ 确认后手动上架。
2. 有订单时：`node scripts/gen-license-key.mjs <订单号>` 输出激活码。
3. 邮件发送激活码 + 使用说明（插件内 帮助 → Pro → 输入激活码）。
4. 在 `docs/pro-sales-log.md`（不公开）记录：日期 / 订单号 / 激活码前缀 / 金额。
